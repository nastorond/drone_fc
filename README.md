# drone-fc

STM32F405 기반 비행제어(FC) 펌웨어를 직접 작성하고, Betaflight와 같은 조건에서 성능을 비교하는 개인 프로젝트.

## 목적

기존 오픈소스 펌웨어를 대조군으로 두고, 밑바닥부터 작성한 펌웨어가 어느 수준에 도달하는지 로그로 측정한다. HAL 없이 레지스터 수준으로 작성하는 것을 원칙으로 한다.

## 대상 하드웨어

| 항목 | 값 |
|---|---|
| FC 보드 | VGOODRCF4 (VGRC) |
| MCU | STM32F405, 168MHz |
| IMU | MPU6000 (SPI) |
| OSD | MAX7456 |
| 수신기 | CRSF (UART5) |
| 블랙박스 저장장치 | 없음 (외장 시리얼 로거 필요) |

## 대조군

Betaflight 4.2.0 (2020-06-14 빌드, 커밋 `8f2d2146`)

- 제어 루프 8kHz, 자이로 샘플링 8kHz
- 설정 대부분 기본값, PID만 일부 조정
- 비교가 끝날 때까지 버전을 고정한다

## 비교 항목

- 제어 루프 주기와 지터, CPU 사용률
- 센서 입력에서 모터 출력까지의 지연
- 호버링 시 자세 오차
- 외란 후 복원 시간

같은 기체·배터리·프로펠러·환경에서 시험을 반복해 평균과 편차를 낸다. 로깅 주기는 두 펌웨어를 동일하게 맞춘다.

## 구조

```
betaflight/   대조군 코드 (4.2.0). 읽기 전용
firmware/     자체 FC 펌웨어
baseline/     version / status / diff all 출력, 보드 사양 기록
logs/         비행 로그 (betaflight/, custom/)
analysis/     로그 분석 스크립트와 그래프
docs/         시험 절차, 실험 기록, 분석 노트
```
